# 基金数据分析爬虫项目

## 项目简介
本项目是一个基于 Python 的基金数据爬虫与分析工具，自动爬取东方财富网基金数据，包含基金收益率、前十大持仓等信息采集，并提供数据清洗脚本，便于后续进行基金分析与可视化。

## 项目结构
```

├── 基金数据分析 /
│   ├── 数据清洗前 /       # 爬取生成的原始 csv 文件存放目录
│   └── 数据清洗后 /       # 清洗完成后的结果数据目录
├── main.py               # 爬虫主程序：爬取基金收益率、前十大持仓等数据
├── clean.py              # 数据清洗脚本：去重、去空、格式化
└── README.md             # 项目说明文档

```

## 环境依赖
```

Python 3.x
pandas
requests

```
安装依赖：
```bash
pip install pandas requests
```

## 使用说明

1. 运行爬虫主程序，自动爬取基金数据并生成 csv 文件：

```
python main.py
```

2. 运行数据清洗脚本，处理原始数据：

```
python clean.py
```

## 功能特点

- 自动创建输出文件夹，避免因路径不存在导致运行报错
- 内置请求头，降低爬取时被网站拦截的概率
- 覆盖基金收益率、前十大持仓等核心数据
- 提供独立数据清洗流程，保证数据质量
